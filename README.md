# SteeLChecker (v1.5.0 Pre) 

Комплексный инструмент для проверки ПК на наличие читов, скрытого ПО и анализа системной активности. Программа предназначена для глубокой проверки системы, анализа Steam-аккаунтов и автоматизации поиска запрещенных модификаций.

## 🚀 Основные возможности

### 🔍 Поиск и анализ файлов (Сканер)
Поиск файлов по базе известных читов и анализ активности системы.

*   **Запуск сканера:** Автоматический поиск подозрительных файлов.
*   **Журнал активности & MuiCache:** Просмотр истории запущенных приложений.
*   **Открытые файлы (DLL):** Мониторинг загруженных библиотек в реальном времени.
*   **Удаленные файлы & История папок:** Поиск следов ранее использовавшегося ПО.
*   **История флешек:** Анализ подключенных внешних накопителей.
*   **Расширенный мониторинг процессов.**

### 👤 Анализ аккаунтов Steam
Сбор информации об активных и ранее использованных аккаунтах на ПК.

*   Отображение текущего активного аккаунта (Аватар, Никнейм, SteamID64).
*   Быстрое копирование SteamID64.
*   Проверка VAC Статуса, типа профиля, даты регистрации и даты скачивания игры.
*   Сохранение истории и отображение удаленных аккаунтов с ПК.

### ⚙️ Дополнительные инструменты
*   **Автоматическая проверка CS2:** Программа автоматически прожимает популярные горячие клавиши читов в запущенной игре для вызова скрытых меню.
*   **Просмотр биндов:** Поиск подозрительных команд в конфигурационных файлах игр.
*   **Проверка реестра Windows:** Глубокий поиск ключей реестра, оставленных читами (даже после удаления файлов).
*   **История браузеров:** Сбор и анализ посещений сайтов (Chrome, Edge, Yandex и др.).
*   **Массовое открытие ссылок:** Автоматическое открытие списка сайтов-провайдеров читов из базы.
*   **Быстрое копирование:** Панель с заготовленными ключевыми словами (ofd, чит, hack) для быстрого поиска.
*   **Почтовые сервисы:** Быстрый доступ к популярным почтовикам (Gmail, Яндекс, Mail.ru, Proton и др.) для проверки привязок.
