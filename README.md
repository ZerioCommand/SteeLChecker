Комплексный инструмент для глубокой проверки ПК на наличие читов, скрытого ПО и анализа системной активности. Программа полностью автономна, не требует установки стороннего софта и автоматически загружает необходимые модули с сервера при запуске.

## Основные возможности

### Поиск и анализ файлов (Службы сканирования)

* **Открытые файлы (DLL):** Мониторинг всех процессов и загруженных библиотек в оперативной памяти в реальном времени с фильтрацией системных путей Windows.


* **История активности (Last Activity):** Сбор логов из системных директорий Recent, RunMRU, Prefetch, TypedURLs, а также декодирование записей UserAssist и MuiCache.


* **Проверка реестра Windows:** Поиск подозрительных ключей в разделах AppSwitched, AppCompatFlags и MuiCache. Встроенная база содержит сигнатуры более 90 известных читов (Neverlose, Midnight, Aimware, Skeet и др.).


* **История браузеров:** Парсинг локальных SQLite баз данных Chrome, Edge, Yandex, Firefox, Opera, Brave, Vivaldi и Avast. Выполняется автоматическая сверка истории с загружаемыми списками подозрительных доменов и заголовков.


* **История флешек и удаленные файлы:** Анализ подключенных внешних накопителей (USB History) и поиск следов ранее удаленных папок через ShellBags.


* **Установленные программы:** Анализ веток реестра Uninstall для выявления скрытых инсталляций.

### Анализ аккаунтов Steam

* **Сбор профилей:** Локальный парсинг файла loginusers.vdf собирает информацию обо всех активных и ранее использованных аккаунтах на устройстве.


* **Интеграция со Steam API:** Программа автоматически подтягивает аватар, никнейм, SteamID64, дату создания аккаунта, тип профиля (скрытый/открытый) и текущий статус VAC.


* **Анализ скачиваний:** Определение даты первого скачивания игры путем анализа локальных директорий userdata.

### Дополнительные инструменты

* **Автоматическая проверка CS2 / CS:GO:** Умная проверка статуса игры перед началом работы. Программа автоматически отправляет в процесс игры последовательность горячих клавиш (Insert, Delete, Home, End, F11, F12 и др.) для вызова скрытых меню софта.


* **Просмотр биндов:** Глубокий рекурсивный поиск подозрительных команд в конфигурационных файлах (.cfg, .vdf) на всех локальных дисках.


* **Быстрый доступ:** Автоматическое массовое открытие почтовых сервисов и сайтов-провайдеров читов из базы для поиска привязок. Панель с заготовками (ofd, чит, hack) для буфера обмена.


* **Скрытые настройки:** Доступ к панели NVIDIA и меню использования трафика Windows.

### Веб-терминал и управление (Live Panel)

* **Панель администратора:** Полноценный веб-интерфейс для мониторинга проверок ПК в реальном времени через технологию Socket.IO. Доступ предоставляется по уникальным токенам с временем жизни 90 минут.


* **Мониторинг записи:** Программа отслеживает запущенные процессы записи экрана (OBS, Bandicam, ShadowPlay и др.) и передает эти данные в веб-панель. Администратор может дистанционно развернуть или принудительно завершить процесс записи.


* **Вердикты и скримеры:** Интерактивное управление сессией из браузера с возможностью вынести вердикт ("Чистый" или "С читом") и отправить на проверяемый ПК звуковой/визуальный скример.
